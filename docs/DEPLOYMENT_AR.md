# دليل النشر السحابي والتشغيل المستقل (Cloud Deployment Guide)

الهدف المحوري لهذا النظام هو **الاستمرار في العمل وإنتاج الفيديوهات ونشرها في السحابة حتى عند إيقاف تشغيل حاسوبك الشخصي وإغلاق بيئة Antigravity بالكامل وبميزانية $0**.

---

## ☁️ خيارات الاستضافة المجانية الدائمة ($0/Month)

### الخيار 1 (الافتراضي والموصى به): سير عمل مجدول عبر GitHub Actions
سير العمل معد مسبقاً في مجلد `.github/workflows/` ويعمل باستقلالية على سيرفرات GitHub:
1. **الجدولة الدورية**: ملف `daily-production.yml` ينطلق وفق cron دوري يغطي الفترات الـ5 بتوقيت نيويورك.
2. **الحفاظ على الحالة (Persistent State)**: يتم تخزين قاعدة البيانات `data/autopilot.db` وسجلات الإنتاج عبر آلية `actions/cache` و `actions/upload-artifact` لضمان عدم ضياع أي سجلات بين الدورات.
3. **الاستهلاك**: يعمل ضمن حدود الباقة المجانية لـ GitHub Actions (2000 دقيقة شهرياً في المستودعات الخاصة، أو غير محدودة في المستودعات العامة).

#### خطوات التفعيل على GitHub:
1. أنشئ مستودعاً جديداً على حسابك في GitHub (خاص أو عام).
2. ارفع مجلد المشروع إليه:
   ```bash
   git init
   git add .
   git commit -m "feat: initial youtube ai autopilot release"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
3. توجه إلى إعدادات المستودع في GitHub:
   👉 **Settings > Secrets and variables > Actions > New repository secret**
4. أضف الأسرار التالية:
   - `YOUTUBE_CLIENT_ID`: معرّف العميل لـ Google OAuth.
   - `YOUTUBE_CLIENT_SECRET`: الرمز السري لـ Google OAuth.
   - `YOUTUBE_REFRESH_TOKEN`: رمز التحديث الناتج بعد ربط قناتك لأول مرة.
   - `GEMINI_API_KEY`: مفتاح Gemini المجاني من Google AI Studio.
   - `ENCRYPTION_KEY`: مفتاح تشفير البيانات.
5. الآن، ستنطلق دورة الإنتاج تلقائياً في السحابة حتى لو كان جهازك مغلقاً.

### الخيار 2 (للمستويات المتقدمة): سيرفر مجاني دائم على Oracle Cloud (Always Free)
توفر شركة Oracle باقة مجانية دائمة تشمل:
- **معالج**: ARM Ampere A1 بعدد 4 أنوية OCPU.
- **ذاكرة عشوائية (RAM)**: 24 جيجابايت.
- **تخزين**: 200 جيجابايت مساحة تخزين مجانية دائمة.

#### خطوات الإعداد على Oracle Cloud:
1. أنشئ خادماً بنظام Ubuntu 22.04 أو 24.04 (ARM أو AMD).
2. قم بتثبيت Docker & Docker Compose:
   ```bash
   sudo apt update && sudo apt install -y docker.io docker-compose
   ```
3. انسخ المشروع وشغله عبر Docker Compose في الخلفية:
   ```bash
   docker compose up -d
   ```
4. سيعمل خادمك على مدار 24 ساعة يومياً، 7 أيام في الأسبوع، باستقلالية مطلقة وبـ 0 دولار شهرياً.

## 🔄 استراتيجية التعافي والتعامل مع التأخيرات (Fault Tolerance)
1. **معالجة فوارق الوقت والتأخيرات**: جدولة GitHub Actions قد تشهد تأخيرات تتراوح بين 5 إلى 20 دقيقة خلال أوقات الذروة. لذلك يقوم النظام بإنتاج الفيديو مسبقاً قبل الموعد بساعتين، وتحديد وقت النشر عبر حقل `publishAt` المدعوم في YouTube API.
2. **استرجاع المهام المفقودة (Missed-Job Recovery)**: في حال تعطل أحد سياقات التشغيل لسبب خارج عن الإرادة، يقوم المشغل التالي بفحص المواعيد السابقة غير المكتملة وتنفيذها فوراً بشكل متسلسل دون تكرار.
3. **منع الازدواجية (Idempotency)**: يعتمد النظام فحص بصمة المحتوى (SHA-256) وسجل قاعدة البيانات لمنع رفع أي فيديو مكرر مرتين تحت أي ظرف.
