# دليل استكشاف الأخطاء وحلها والتعافي الذاتي (Troubleshooting & Recovery)

يوفر هذا الدليل تشخيصاً وحلولاً سريعة لجميع الحالات الاستثنائية التي قد تطرأ أثناء تشغيل نظام **YouTube AI Autopilot**.

---

## 🔍 التشخيص السريع للصحة العامة
يمكنك دائماً فحص سلامة جميع مكونات النظام بأمر مباشر:
```bash
source venv/bin/activate
python main.py health
```
أو من خلال واجهة لوحة التحكم في صفحة **"الأخطاء والمشاكل"** أو **"موارد السحابة"**.

---

## 🛠️ المشاكل الشائعة وطرق علاجها

### 1. انتهاء صلاحية رمز YouTube OAuth أو إلغاؤه (Token Expired / Revoked)
- **الأعراض**: ظهور خطأ `invalid_grant` أو فشل فحص المصادقة في لوحة التحكم.
- **السبب**: في مرحلة الاختبار التجريبي (Testing) في Google Cloud Console، تنتهي صلاحية الرموز كل 7 أيام.
- **الحل**:
  1. ادخل إلى Google Cloud Console > **OAuth Consent Screen**.
  2. اضغط على زر **"Publish App"** لتحويل التطبيق إلى وضع الإنتاج (Production). سيجعل ذلك رمز التحديث دائمًا ولا ينتهي.
  3. توجه إلى لوحة التحكم العربية في صفحة **"الأمان والحسابات"** واضغط على **"إعادة ربط القناة"** لتحديث الرمز فوراً.

### 2. تجاوز حصة يوتيوب اليومية (YouTube Quota Exceeded - HTTP 403)
- **الأعراض**: رسالة `quotaExceeded` في السجلات.
- **سلوك النظام**: يكتشف النظام تجاوز الحصة تلقائياً ويوقف محاولات الرفع، ويحفظ الفيديوهات المنتجة في المجلد المحلي `output/` لاستكمال رفعها تلقائياً فور تجدد الحصة عند منتصف الليل بتوقيت المحيط الهادئ.
- **الإجراء المطلوب**: لا شيء؛ سيتعافى النظام تلقائياً دون فقدان أي فيديو تم إنتاجه.

### 3. خطأ في رندرة الفيديو أو فقدان الخطوط في FFmpeg
- **الأعراض**: فشل خطوة `FFmpeg assembly` مع رسالة خطأ متعلقة بترميز الفيديو أو الخطوط.
- **الحل**:
  - تأكد من تثبيت الحزم المطلوبة:
    ```bash
    sudo apt-get install -y ffmpeg fonts-dejavu-core fonts-noto
    ```
  - تحقق من دعم FFmpeg لترميز H.264:
    ```bash
    ffmpeg -encoders | grep libx264
    ```

### 4. تجاوز معدل طلبات Gemini API (Rate Limit 429)
- **الأعراض**: تأخر مؤقت في توليد الأفكار أو النصوص مع كود 429.
- **سلوك النظام**: يتضمن محرك الذكاء الاصطناعي آلية تراجع أسي ذكية (Exponential Backoff) مع انتظار تلقائي، كما يحتوي على قوالب نصية علمية احتياطية جاهزة تُستخدم تلقائياً عند انقطاع الاتصال الخارجي دون توقف الإنتاج.

### 5. نقص مساحة التخزين على السيرفر (Low Disk Space)
- **الأعراض**: تنبيه برتقالي في لوحة التحكم يفيد بأن المساحة المتبقية أقل من 5 جيجابايت.
- **الحل**:
  - يقوم النظام تلقائياً بتنظيف ملفات الإطارات المؤقتة (`temp/`) بعد انتهاء إنتاج كل فيديو بنجاح.
  - لحذف الفيديوهات القديمة التي تم رفعها بنجاح مسبقاً وتفريغ المساحة:
    ```bash
    find output/ -name "*.mp4" -mtime +7 -delete
    ```

### 6. إعادة محاولة المهام الفاشلة من لوحة التحكم (One-Click Retry)
- توجه إلى صفحة **"الأخطاء والمشاكل"** في لوحة التحكم العربية.
- ستجد قائمة مفصلة بالأخطاء ومستوياتها (حرج، خطأ، تحذير).
- بجانب أي مهمة فشلت لسبب عابر، اضغط على زر **"إعادة المحاولة"** لتشغيل خط الإنتاج مجدداً فورياً.

### 7. التراجع عن التوقف الطارئ (Deactivating Emergency Stop)
- إذا تم تفعيل زر التوقف الطارئ الأحمر سابقاً:
  - توجه إلى الشريط العلوي أو صفحة الأمان واضغط على **"إلغاء التوقف الطارئ"**، أو قم بتعيين `EMERGENCY_STOP=false` في ملف `.env` لإعادة التشغيل الآلي.
