## 📊 توزيع حصص YouTube Data API v3 اليومية

تمنح Google افتراضياً لكل مشروع في Google Cloud حصة يومية قدرها **10,000 وحدة حصة (Quota Units)** تتجدد يومياً عند منتصف ليل توقيت المحيط الهادئ (PT).

### جدول تكلفة العمليات البرمجية:
| العملية البرمجية | نقطة النهاية (Endpoint) | تكلفة الحصة (وحدة) |
| :--- | :--- | :--- |
| **رفع فيديو كامل** | `videos.insert` | **1,600 وحدة** |
| **تحديث الصورة المصغرة** | `thumbnails.set` | **50 وحدة** |
| **تحديث البيانات الوصفية** | `videos.update` | **50 وحدة** |
| **إضافة الفيديو لقائمة تشغيل** | `playlistItems.insert` | **50 وحدة** |
| **قراءة بيانات فيديو** | `videos.list` | **1 وحدة** |
| **قراءة بيانات القناة** | `channels.list` | **1 وحدة** |

### الموازنة اليومية للهدف (4 شورتس + 1 فيديو طويل = 5 فيديوهات يومياً):
- **عمليات الرفع (5 فيديوهات × 1,600)** = **8,000 وحدة**
- **رفع الصور المصغرة المخصصة (5 × 50)** = **250 وحدة**
- **تحديث العناوين والوصف (5 × 50)** = **250 وحدة**
- **استعلامات القراءة والمتابعة** = **~50 وحدة**
- **الإجمالي اليومي المستهلك**: **8,550 وحدة**
- **الرصيد المتبقي للأمان**: **1,450 وحدة** (هامش أمان لتجنب تجاوز الحصة).

> ⚠️ **تنبيه الشفافية (سياسة يوتيوب للمشاريع غير المدققة)**:
> تفرض سياسات Google منذ يوليو 2020 على المشاريع الجديدة غير المعتمدة رسمياً رفع الفيديوهات بوضعية **"خاص (Private)"** حتى يتم تقديم طلب تدقيق الامتثال المجاني (YouTube API Compliance Audit). النظام يتعامل مع هذا القيد بأمان تام، حيث يرفع الفيديوهات بصيغة مسودة خاصة ومجدولة، ويشرح للمستخدم الخطوات البسيطة لطلب التحقق المجاني إذا رغب في النشر العلني التلقائي بالكامل.
