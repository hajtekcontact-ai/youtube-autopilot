# دليل العمليات والتشغيل اليومي (Operations Manual)

نظام **YouTube AI Autopilot** مصمم ليعمل باستقلالية تامة دون الحاجة لأي أوامر طرفية (Terminal) يومية، من خلال لوحة تحكم عربية متكاملة.

---

## 🖥️ أقسام لوحة التحكم العربية (Arabic Dashboard)

### 1. نظرة عامة (Overview)
- **المؤشرات الحيوية**: إجمالي الفيديوهات المنتجة، الفيديوهات المنشورة اليوم، الفيديوهات قيد المعالجة، والأخطاء إن وجدت.
- **التحكم الفوري**: زري إيقاف مؤقت (Pause) واستئناف النشر (Resume).
- **زر التوقف الطارئ (Emergency Stop)**: زر أحمر بارز في الشريط العلوي لإيقاف جميع عمليات المعالجة والرفع فوراً عند الحاجة.
- **جدول مواعيد اليوم**: يعرض الفيديوهات المقررة لكل فترة مع حالتها (مكتمل، جاري المعالجة، في الانتظار).
- **سجل النشاط المباشر**: تقرير لحظي عن كل خطوة يقوم بها الذكاء الاصطناعي.

### 2. تقويم النشر (Publishing Calendar)
- يعرض جدول النشر اليومي بتوقيت نيويورك (`America/New_York`) الذي يراعي التوقيت الصيفي تلقائياً:
  - **09:00 ص**: فيديو قصير (Short)
  - **12:00 م**: فيديو قصير (Short)
  - **03:00 م**: فيديو قصير (Short)
  - **06:00 م**: فيديو طويل (Long Video: 5 إلى 10 دقائق)
  - **09:00 م**: فيديو قصير (Short)
- يتم إنتاج كل فيديو قبل موعد نشره بساعتين لضمان الجاهزية والرفع المبكر.

### 3. مكتبة الفيديو (Video Library)
- استعراض جميع الفيديوهات المصممة مع الصور المصغرة، العناوين، مدة الفيديو، وتصنيف المحتوى.
- فلاتر للبحث والتصفية حسب الحالة (مسودة، جاهز، مجدول، منشور، فشل).
- إمكانية تشغيل ومعاينة الفيديوهات مباشرة من المتصفح.

### 4. مدير المحتوى والذكاء الاصطناعي (Content Manager)
- استعراض الأفكار المقترحة والمسودات ومصادرها.
- إضافة مواضيع جديدة يدويًا أو ترك المحرك يولد أفكاراً في مجالات العلوم والتكنولوجيا والشروحات التعليمية.
- محرك فحص الأصالة والتكرار: يمنع تكرار المواضيع أو إعادة إنتاج محتوى مشابه خلال 30 يوماً.

### 5. خط إنتاج الفيديو (Production Pipeline)
- متابعة مراحل إنتاج الفيديو خطوة بخطوة:
  1. كتابة النص والخطاف (Hook)
  2. التدقيق العلمي والحقائق (Fact Checking)
  3. التوليد الصوتي الطبيعي (Neural TTS)
  4. تصميم وتوليد الإطارات الرسومية المتحركة
  5. مواءمة وتوليد الترجمة التلقائية (Subtitles/Captions)
  6. معالجة الفيديو النهائي عبر FFmpeg مع موازنة الصوت
  7. توليد الصورة المصغرة (Thumbnail) بأبعاد عالية الوضوح
  8. فحص الجودة الشامل (QC Validation) قبل الرفع

### 6. تحليلات يوتيوب واستراتيجية التكيف (Analytics & Bandit Strategy)
- مراقبة المشاهدات، وقت المشاهدة، ومعدل النقر إلى الظهور (CTR).
- تحليل أداء الفيديوهات في نوافذ زمنية محددة: 48 ساعة، 7 أيام، 28 يومًا.
- خوارزمية **Multi-Armed Bandit**:
  - إذا حقق أسلوب معين (مثلاً خطاف سردي مباشر أو وتيرة أسرع) نجاحاً، يزيد النظام من استخدامه تلقائياً بنسبة مدروسة.
  - إذا ضعف الأداء، يتم تحليل السبب (العنوان، الصورة المصغرة، أو وتيرة الفيديو) واختبار بدائل جديدة.

### 7. حصص API والتكاليف (Quotas & Costs)
- شريط بياني لحصة YouTube Data API اليومية (10,000 وحدة افتراضياً).
- متابعة استخدام Gemini API المجاني.
- مفتاح أمان التكلفة (**Cost Kill Switch**): يضمن عدم تفعيل أي خدمة مدفوعة، وإيقاف العمليات تلقائياً إذا حاول أي مزود فرض رسوم.

---

## 🔒 التحكم في العمليات بدون أوامر
- **إيقاف النشر**: بنقرة واحدة من لوحة التحكم، يتم تعليق الرفع التلقائي دون إيقاف إنتاج المسودات.
- **التوقف الطارئ**: يمنع أي اتصال بالخوادم الخارجية ويغلق خط الإنتاج فوراً.
- **إعادة المحاولة للأخطاء القابلة للتعافي**: يمكن الضغط على زر "إعادة المحاولة" بجانب أي خطأ من صفحة "الأخطاء والمشاكل" لإعادة تشغيل العملية.
